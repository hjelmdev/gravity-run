Vilket dödsljud passar bäst?

Tryck på spela för att lyssna. Varje förslag hörs två gånger. Börja med låg volym.

1. Dov träff

En kort smäll utan röst.

Öppna ljudfilen separat

2. Arkad

Ett snabbt fallande ”bwopp”.

Öppna ljudfilen separat

3. Tecknat uff

En syntetisk variant med mer träff och mindre utdragen röst.

Öppna ljudfilen separat
