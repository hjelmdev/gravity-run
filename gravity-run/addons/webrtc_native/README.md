# Native WebRTC extension

This directory contains the Windows x86_64 debug and release binaries from the
official [godotengine/webrtc-native 1.2.1-stable release](https://github.com/godotengine/webrtc-native/releases/tag/1.2.1-stable).
The downloaded upstream archive SHA-256 was
`F37D03DA03DA3FF0D092542A04586644F889135CB7A1C3566AD57513203A553B`.

The Godot Web export explicitly excludes this directory and continues to use
the browser's built-in WebRTC implementation. License notices for the upstream
extension and its bundled libraries are included alongside the binaries.
