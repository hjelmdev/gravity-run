# Gen16 återkoppling: ljud, mynt och periodiska stopp

Användaren rapporterar från sin andra dator två/annorlunda ljud vid gravitationsbyte, hörbara rullande hinderkollisioner, mynt som ibland blir kvar trots genomlöpning och stora återkommande stopp i musik och spel. SP/MP/roll/webbläsare frågat asynkront; dra inte slutsats om dator/nätverk utan evidens.

Baslinje: publicerad gameplay80d2e44, Gen16/API.12, build ghost-gen16-density-biome-80d2e44-20261006. Root samordnar befintlig Luna, granskar faktisk diff och slutverifierar release. Bevara unrelated dirty, äldre seedhashar, myntkonto/idempotens, grottfix, touchfix, valt dödsljud och capturefeature.

1. Återskapa accepterad flip genom verkliga SP/MP-scener med event_started-logg. Räkna faktiska ljud per handling, identitet och tid; skilj gravity_flip från coin/ghost/barrel/rock samt dubbla dolda sceninstanser eller gamla browserflikar. Flipfilen ändrades inte i Gen16. Ändra inte ljudassets blint. Bekräfta avsedd ljudpolicy för synliga hinderkollisioner och om osynliga/offscreen events läcker ljud.
2. Återskapa myntgenomlöpning med verkliga render-/simpositioner och samtliga collectibleformer. Granska svept kontakt, interpolation, fördröjd host/resolution/retry/baseline och rollback. Visuell kontakt ska starta delad animation direkt; kontoavräkning förblir auktoritativ/idempotent. Ingen gratis insamling utanför korrekt kontaktyta eller andra walletvägar.
3. Mät periodiska synkrona kostnader vid Gen15/Gen16 jämförbara seeds/distans/hastighet: generator horizon/safetygates, source/resolved rebuild, myntplanner, worldstep, renderprofil och event/SFX. Musikstopp kan bero på arbetsstopp; hårdvara/nätverk är hypotes tills mätt. Identifiera konkret stall innan ändring. Bounded diagnostik, inga kontinuerliga fullimage-readbacks/uppblåsta loggar i normalspel. Bevara determinism om arbete cacheas/budgeteras och inga hazards spawnar för sent.
4. Rapportera REVIEW_READY med reproducerade fynd, riktad faktisk scene/regression före/efter samt begränsningar. Root granskar och låter Luna rätta. Ingen live innan rootapproval. Därefter scoped Azurepush, nödvändiga granskade migrationer bara vid verkligt kontraktsbehov, rent exaktcommit Web/Pages, workflow/head/bådaBUILD_ID/loaders och root oberoende publicPCKhash. Bevara gamla seeds om gameplay ändras; undvik onödig API/genbump för presentation/prestanda.

Seriella bounded egna Godottester med PID/barncleanup; bevara användarens editor och andras arbete. Vid kapacitetsfel durable checkpoint så root kan ta över. Återförsök inte nekade livehandlingar utan faktisk relevant auktorisation. Meddela meningsfull milstolpe, konkret blockerare eller verifierad release, var annars tyst.

Ny användarevidens: samma problem i SP och MP. DesktopChrome extra/annorlunda ljud tydligast, Firefox mindre, Chrome mobil hör inte dessa men uppspelning av ljud kommer flera sekunder efter event. Skilj engine eventtimestamp/AudioStreamPlayer.play från faktisk browserAudioContext/outputtid. Exporten är thread_support=false; granska stream/sample backend och stale buffered audio efter stall/resume innan ändring. Mobil Android/iPhone och högtalare/Bluetooth frågat asynkront; det blockerar inte fortsatt utredning.
