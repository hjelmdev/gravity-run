## Gen21 behavior

- The rubber barrel reverses direction on its designated block or solid step without consuming either entity and remains lethal to runners.
- After the two moving rebounds, another solid contact parks it one pixel clear of the face in a visible, stationary, still-lethal spent state. It no longer moves or interacts, bounding the bounce loop without destroying or hiding either entity. The spent state is included in the shared baseline and Gen21 state hash.
- Gen21 baseline format 5 now includes a validated dynamic-pose row for every ordinary, spiked, and rubber barrel. This is necessary because applying the host simulation tick without restoring a moving ordinary barrel left the guest at its initial pose. Baseline formats 2–4 retain their existing ledger-only restore path.
- On Gen21 baseline restore, the validated host tick is assigned before saw-history reconstruction. This ensures late-join barrel and saw contact histories are both available at the same authoritative tick; the older baseline restore order is unchanged.
- The same shared model drives SP and MP. Gen21 version/API/manifest/baseline are 21 / `.17` / 14 / 5; visible project label is `2026.10.08-gen21-rubber-barrel-weather`.
- Weather is a shared SP/MP backdrop layer driven by presentation time and course position. Each primitive is omitted when it cannot fit wholly inside its biome fragment. No per-frame nodes, textures, or RNG are created; visible lava embers use small CPU-side polygon arrays bounded by viewport cells.
